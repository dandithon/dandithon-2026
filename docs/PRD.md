## 1. 프로젝트 개요

### 1.1 서비스 소개

**시장에 가면**은 실제 전통시장을 탐험하며 캐릭터를 성장시키고, 음식 구매와 퀘스트 수행을 통해 장비와 배지를 수집하는 위치 기반 전통시장 RPG 서비스입니다.

대구 서문시장을 2D 픽셀 아트 게임 공간으로 구현하여 사용자의 실제 이동을 게임 속 캐릭터의 이동과 연결합니다.

사용자는 가게를 탐험하고, 상인 NPC와 상호작용하며, 가상 코인으로 음식을 구매하고 다양한 보상을 획득할 수 있습니다.

### 1.2 핵심 콘셉트

> 현실의 발걸음이 게임 속 모험이 되는 전통시장 RPG

### 1.3 프로젝트 목표

- 전통시장 방문을 새로운 게임 경험으로 전환
- 젊은 세대의 전통시장 방문 및 관심 유도
- 실제 시장 구조와 가게를 활용한 탐험 경험 제공
- 음식 구매에 따른 보상으로 지속적인 참여 유도
- AI 예상 대기시간 및 혼잡도 시각화로 사용자 편의성 향상

## 2. 지역 가치 및 문제 정의

### 2.1 지역적 배경

대구 서문시장은 다양한 먹거리와 상점이 모여 있는 전통시장입니다.

본 서비스는 전통시장의 다음과 같은 경험에 주목합니다.

- 골목을 탐험하며 새로운 가게를 발견하는 즐거움
- 다양한 먹거리를 직접 선택하고 경험하는 재미
- 상인과 손님이 소통하는 친근한 분위기
- 여러 사람이 모여 만들어 내는 시장의 활기

### 2.2 지역 가치의 재해석

| 지역에서 발견한 가치 | 서비스에서의 재해석 |
|---|---|
| 시장 골목을 탐험하는 즐거움 | 2D RPG 맵 탐험 |
| 새로운 가게와 음식을 발견하는 재미 | 상점 및 상품 수집 경험 |
| 시장의 활기찬 분위기 | NPC 및 혼잡도 시각화 |
| 시장 방문의 성취감 | 퀘스트와 경험치 보상 |
| 다양한 먹거리 경험 | 음식별 장비 및 배지 수집 |

### 2.3 해결하고자 하는 문제

본 프로젝트는 젊은 세대가 전통시장을 보다 친근하고 재미있게 경험할 수 있도록 하는 것을 목표로 합니다.

다음 문제 가설은 사용자 리서치를 통해 검증할 예정입니다.

- 젊은 세대는 전통시장을 방문할 동기가 부족할 수 있다.
- 전통시장에 어떤 가게와 먹거리가 있는지 파악하기 어려울 수 있다.
- 기존의 정보 탐색 방식만으로는 시장의 활기와 재미를 충분히 전달하기 어려울 수 있다.

## 3. 타깃 사용자

### 3.1 주요 타깃

- 전통시장 방문 경험이 적은 10~20대
- 게임형 콘텐츠에 익숙한 젊은 사용자
- 지역 먹거리와 새로운 경험에 관심이 있는 사용자

### 3.2 사용자 니즈

- 전통시장을 친근하고 재미있게 경험하고 싶다.
- 시장의 가게와 음식을 쉽게 발견하고 싶다.
- 시장을 탐험하면서 새로운 목표와 보상을 얻고 싶다.
- 복잡한 정보를 읽지 않고 직관적으로 가게의 혼잡도를 확인하고 싶다.

※ 사용자 니즈는 현재 기획 가설이며, 설문 및 인터뷰를 통해 검증합니다.

## 5. 기능별 상세 요구사항

### 5.1 위치 기반 RPG 탐험

#### 기능 설명

사용자가 실제 서문시장을 이동하면 게임 속 캐릭터도 함께 이동하는 시스템입니다.

#### 요구사항

- 실제 사용자 위치 기반 캐릭터 이동
- 탑다운 시점의 2D 픽셀 아트 시장 맵 제공
- 지도 확대 및 축소
- 시장 내 가게 및 NPC 표시
- 가게 선택 시 상호작용
- 조이스틱 ON/OFF 지원

#### 조이스틱 정책

**조이스틱 OFF**
- 실제 사용자 위치를 기반으로 캐릭터 이동

**조이스틱 ON**
- 가상 조이스틱을 이용해 캐릭터 직접 조작
- 실제 방문하지 않아도 시장을 가상 탐험 가능

#### 유의사항

- 가상 이동과 실제 이동을 구분해야 합니다.
- 조이스틱 이동만으로 실제 방문 인증이 완료되지 않도록 설계합니다.
- 실내 GPS 정확도 및 층수 인식 방식은 개발팀 검토가 필요합니다.

---

### 5.2 AI 예상 대기시간 및 혼잡도

#### 기능 설명

AI가 가게별 예상 대기시간을 산출하고, 이를 게임 속 NPC 대기줄과 혼잡도로 표현합니다.

#### 요구사항

- 가게별 예상 대기시간 제공
- 예상시간에 따른 NPC 수 변화
- 가게 주변 혼잡도 시각화
- 가게 선택 시 예상시간 확인

#### 혼잡도 표현 기준 예시

| 예상 대기시간 | NPC 수 | 혼잡도 |
|---|---|---|
| 0~5분 | 1~2명 | 여유 |
| 5~10분 | 3~5명 | 보통 |
| 10~20분 | 6~10명 | 혼잡 |
| 20분 이상 | 10명 이상 | 매우 혼잡 |

※ 혼잡도 구간 및 NPC 수는 개발 과정에서 변경될 수 있습니다.

#### AI 활용 계획

- 주문량 및 조리시간 등의 데이터를 입력값으로 활용
- 가게별 예상 대기시간 산출
- 예상 대기시간을 혼잡도 단계로 변환
- 혼잡도 단계에 맞춰 NPC 대기줄 표시

#### 데이터 관련 유의사항

- 실제 주문량 및 대기 데이터 확보 여부 확인 필요
- AI 모델 및 예측 방식은 개발팀에서 결정
- 실제 데이터가 없는 경우 시연용 데이터를 사용할 수 있음
- 시연용 정보는 실제 대기시간으로 오인되지 않도록 구분

### 5.3 가게 상호작용

#### 기능 설명

사용자가 시장 내 가게를 선택하면 해당 가게의 NPC 및 상품 정보를 확인할 수 있습니다.

#### 요구사항

- 가게 NPC 상호작용
- 가게 소개 및 한 줄 설명
- 판매 상품 목록 조회
- 상품 이미지 및 가격 표시
- 상품 수량 선택
- 구매 화면 이동

### 5.4 게임 코인 기반 Mock 결제

#### 기능 설명

사용자가 보유한 게임 코인으로 음식을 구매하는 기능입니다.

#### 요구사항

- 보유 코인 조회
- 상품 선택 및 수량 변경
- 총 구매 금액 계산
- 구매 시 코인 차감
- 구매 완료 안내
- 주문 내역 생성
- 음식별 구매 횟수 누적

#### 결제 예시

| 항목 | 내용 |
|---|---|
| 보유 코인 | 1,250 |
| 구매 상품 | 떡볶이 1개 |
| 상품 가격 | 300코인 |
| 결제 후 잔액 | 950코인 |

#### 결제 정책

- 실제 현금 결제는 지원하지 않음
- 실제 음식 주문 및 결제는 발생하지 않음
- 실제 PG 결제 시스템 미구현
- QR 인증 기능 미구현

#### 예외 상황

- 보유 코인이 부족하면 구매 불가
- 상품 수량이 0개이면 구매 불가
- 구매 실패 시 코인 차감 및 주문 생성이 발생하지 않아야 함
- 동일한 결제 요청의 중복 처리 방지 필요

### 5.5 영수증 시스템

#### 기능 설명

사용자가 구매한 음식의 주문 내역과 현재 조리 상태를 확인할 수 있습니다.

#### 주문 상태

| 상태 | 설명 |
|---|---|
| 조리 중 | 주문 접수 및 준비 중 |
| 조리 완료 | 음식 준비 완료 |
| 리뷰 작성 완료 | 해당 음식의 리뷰 작성 완료 |

#### 요구사항

- 구매한 음식 목록 조회
- 음식 이미지 및 수량 표시
- 주문 상태 표시
- 주문 성공 직후 리뷰 작성 버튼 활성화 (canReview 기준)
- 리뷰 등록 후 작성 완료 표시

#### MVP 구현 방식

- 실제 점주용 주문 관리 기능은 구현하지 않음
- 시연용 Mock 주문 상태를 활용
- 상태 변경 시점 및 방식은 개발팀과 협의

---

### 5.6 리뷰 시스템

#### 기능 설명

게임 내 주문 성공 직후부터 조리 완료를 기다리지 않고 리뷰를 작성할 수 있습니다.

#### 요구사항

- 주문한 음식은 조리 완료를 기다리지 않고 리뷰 작성 가능
- 별점 및 리뷰 내용 입력
- 리뷰 등록
- 작성한 리뷰 목록 조회
- 프로필의 내 리뷰 탭 연동

#### 사용자 흐름

영수증 확인
→ 리뷰를 아직 작성하지 않은 주문 선택
→ 리뷰 작성
→ 리뷰 등록
→ 내 리뷰에 추가

※ 해당 리뷰는 실제 음식 구매 후기와 혼동되지 않도록 게임 내 체험 리뷰임을 구분하는 정책을 검토합니다.

## 6. 전체 화면 구성

## 7. 전체 사용자 흐름

### STEP 1. 게임 시작
- 시작 화면 진입
- 시작하기 선택
- 메인 화면 이동

### STEP 2. 시장 탐험
- 위치 기반 캐릭터 이동
- 필요시 조이스틱 활성화
- 맵 확대 및 축소
- 주변 가게 확인

### STEP 3. 혼잡도 확인
- 가게별 예상 대기시간 확인
- NPC 대기줄 확인
- 가게 선택

### STEP 4. 가게 상호작용
- NPC 대화
- 가게 소개 확인
- 판매 상품 확인

### STEP 5. 음식 구매
- 상품 선택
- 수량 선택
- 코인 결제
- 구매 완료

### STEP 6. 영수증 확인
- 주문 내역 확인
- 조리 상태 확인
- 리뷰 미작성 주문 확인

### STEP 7. 리뷰 작성
- 리뷰 작성 버튼 클릭
- 별점 및 리뷰 입력
- 리뷰 등록
- 내 리뷰에 기록

### STEP 8. 보상 획득
- 음식 누적 구매 횟수 증가
- 장비 획득 조건 확인
- 배지 획득 조건 확인
- 획득 보상 지급

### STEP 9. 프로필 확인
- 가방에서 장비 확인
- 획득 장비 착용
- 내 리뷰 확인
- 수집한 음식 및 배지 확인

### STEP 10. 재탐험
- 캐릭터 꾸미기
- 다른 가게 탐험
- 새로운 음식 구매
- 추가 장비 및 배지 획득

## 13. 서비스 핵심 가치

> 전통시장을 단순히 방문하는 공간이 아닌,
> 탐험하고 수집하며 성장하는 게임 공간으로 전환한다.

**시장에 가면**은 대구 서문시장에서 발견한 경험을 위치 기반 RPG로 재해석하여, 젊은 세대가 전통시장을 더욱 친근하고 즐겁게 경험할 수 있도록 합니다.

### 2026-11-05 서문분식 AI 시제품 범위
- 서문분식 네 메뉴 수량으로 주문 준비시간을 예측하는 Random Forest를 자체 조리 시뮬레이션 5,000건으로 학습한다. 실제 매장 데이터/실측 정확도와 구분한다.
- 기존 주문의 남은 준비시간에 새 주문의 예측 준비시간을 더한다. 대기열은 접수 순서 처리라는 시연 가정이다.
- 서문분식 NPC 수는 가상 대기시간 3분당 1명(올림), 0분은 0명, 최대 10명. 다른 가게의 기존 기준은 유지한다.
- 이번 작업은 백엔드 및 학습 코드만 구현한다. 프론트 연동 전까지 주문 적용은 기본 비활성화하며 예측 견적 API로 검증한다.
- 가상 분/실제 초 배속을 응답에 공개한다. 운영 정확도 검증은 실제 접수·준비 완료 기록을 확보한 후 별도로 진행한다.
