# Character sprite assets

Generated with the built-in image_gen tool on 2026-11-01. Original character and outfit art in this repository were used as references. Existing source assets are preserved.

The atlases have a transparent background and a 3 × 3 grid: front, right, back rows; idle and two stride columns. Left-facing movement mirrors the right-facing frames. PlayerCharacter registers the cells, selects head/body/feet bands independently, and overlays the scarf. Profile and map share this renderer.

## Base prompt

Use case: stylized-concept. Create a production transparent PNG sprite sheet for a top-down 2D pixel RPG. References: character-front.png identity and base clothes; character-side.png side identity; 40-41-imgImage87.png back view. Same brown spiky-haired boy, cream long sleeve shirt, blue trousers, brown boots, ochre backpack with dark straps. Preserve the charming low-resolution pixel art style, black/dark-brown outlines, no blur. EXACT layout: 3 columns and 3 rows of equal square cells in a square canvas, no margins between cells. Each character centered horizontally inside its cell, feet baseline at 88% of cell height, head at 12%, identical scale. Row 1 front facing toward viewer, row 2 right-facing profile, row 3 back facing away. Column 1 standing idle, column 2 walking left leg forward and opposite arm forward, column 3 walking right leg forward and opposite arm forward. Clearly alternate legs and arms, keep head and torso registration aligned across columns. All 9 cells full-body, same head size and character height. Empty space genuinely transparent, NO floor shadows, NO text, NO grid lines, NO extra objects. The sprite sheet is consumed as a precise 3-by-3 grid.

Preserve EXACT canvas size, 3 columns x 3 rows, character centers, feet baselines, all 9 body poses, head shapes and sizes, face identity, hair, backpack, leg positions, and transparent background. Dress ALL NINE characters in a red baseball cap with a small cream horizontal mark, red open varsity jacket with cream sleeve stripes over the same cream shirt, and red sneakers with cream soles. Match reference clothing design. Row 1 front; row 2 right side; row 3 back. Columns idle, walk leg A, walk leg B. Do not add a scarf. Maintain pixel alignment with input so head, torso, legs can be layered with original atlas. The cap must fit the existing hair silhouette, do not increase head size or shift head down. Keep blue trousers and backpack unchanged. Ensure the right-facing walk frames have opposite arm and leg swing between columns two and three. NO text or grid lines or floor shadows. Transparent PNG.

## Scarf prompt

Do NOT render characters, heads, faces, hats, jackets, backpacks, arms or legs. Scarves must fit directly around each character's neck when this transparent atlas is overlaid on reference 1, same canvas 1254 by 1254. Front row neck around y245 and x225,625,1025; right-profile row neck around y635; back row neck around y1032. Scarf width approximately 110 pixels front/back, 65 pixels side; hanging tails 65 pixels long.
