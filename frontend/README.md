# 단디톤 · 서문시장 프론트엔드

React 19 + Vite 7 + Tailwind CSS 4. Figma `Section 1`의 확보된 디자인과 원본 에셋을 바탕으로 구현했습니다. Figma 파일에는 쓰기 작업을 하지 않았습니다.

## 실행

저장소 루트에서 `cd frontend`로 이동하세요. 최초 실행 시 `npm ci`로 패키지를 설치하고, 이후에는 아래 명령만 실행하면 됩니다.

```sh
npm run dev
```

터미널의 `Local` 주소(기본 `http://127.0.0.1:5173/`)를 열면 됩니다. 해당 포트가 사용 중이면 다음 빈 포트를 자동으로 사용하므로 터미널에 표시된 주소를 확인하세요. 소스 파일을 저장하면 화면에 변경 사항이 반영됩니다. 종료는 `Ctrl + C`입니다.

다른 컴퓨터에서 처음 설치할 때는 Node.js 22.12 이상을 준비한 뒤 `npm ci`를 한 번 실행하세요.

배포용 빌드 결과를 확인할 때만 아래 명령을 사용합니다:

```sh
npm run build
npm run preview -- --port 5173
```

제한된 Windows 환경에서도 개발 서버가 실행되도록 React 의존성 경로는 Node.js로 해석하고, esbuild의 상위 폴더 자동 탐색을 제한했습니다. 이 설정은 `vite.config.js`에 포함되어 있습니다.

## 구현 범위

- 시작 화면 → 시장 지도 → 서문분식 → 메뉴 / 리뷰
- 지도 방향 조작, 방향별 캐릭터, 가게·화단 충돌 처리, ON/OFF, 가상 방문 기록, 가게별 즐겨찾기
- 메뉴 상세, 1~99개 수량, 장바구니, 코인 검증과 목업 주문
- 영수증: 신규 주문은 15초 후 조리 완료, 리뷰 작성 가능
- 리뷰 작성·별점·로컬 저장, 일일 미션 보상 중복 방지
- Esc 닫기, 팝업 포커스 제한, 배경 키보드 접근 차단
- 402×874 원본 아트 비율 유지, 좁은 화면에서는 비례 축소

## 아직 구현하지 않은 부분 / 원본과 차이

- 백엔드 연동, GPS 이동, 지도 확대·축소, 구매 횟수 누적, 장비·배지·경험치 시스템은 미구현입니다. 조작 OFF는 이동 버튼 숨김/키보드 비활성화이며 GPS 모드가 아닙니다.
- 방문 기록과 보상은 로컬 데모 상태이며 실제 방문 인증이 아닙니다.

- 주문 완료 전용 화면(113:996): Figma Starter MCP 사용량 제한으로 상세 컨텍스트·캐릭터 에셋을 받지 못했습니다. 현재 주문 성공 메시지 후 영수증을 엽니다. 제한 해소 후 이 화면을 추가해야 합니다.
- 프로필 프레임은 원본이 비어 있어 별도 화면을 만들지 않았습니다.
- AI 요약, 실제 영업 정보, 추가 퀘스트·이벤트는 준비 중 안내만 표시합니다.
- 칼국수·호떡·카페는 공통 가게 화면과 임시 메뉴를 사용합니다. 신규 메뉴 이미지는 이모지입니다.
- 사진 미션은 원본의 완료 상태를 재현한 샘플입니다. 카메라·실제 사진 인증은 없습니다.
- 리뷰 작성 폼과 장바구니는 상호작용을 위해 추가한 임시 UI입니다.
- 원본의 리뷰 개수(가게 정보 348 / 탭 358)는 그대로 유지했습니다.
- 픽셀 아트의 좌표와 이미지 크롭은 유지하고 데이터 목록은 flex/grid로 구성했습니다. 반응형 비례 축소나 폰트 렌더링에 따라 작은 차이가 있을 수 있습니다.

## 구조와 백엔드 연결

- src/pages: 시작·지도·가게·메뉴/리뷰 페이지
- src/components: 이미지 버튼, 지도 아트, 공통 다이얼로그, 주문·영수증·퀘스트
- src/api/market.js: 비동기 API 어댑터. 서버 주소를 임의로 만들거나 호출하지 않습니다.
- src/mocks/fixtures.js: 샘플 메뉴·영수증·리뷰
- src/assets/figma.json: 화면 ID별 로컬 원본 이미지 경로
- public/assets: 다운로드한 Figma 원본 에셋
- public/fonts: NeoDunggeunmo, Mona12 Text KR 및 라이선스
- src/styles/global.css: Tailwind와 폰트·테마 선언
- tests/market.test.js: 주문 검증, 코인, 리뷰, 보상, 장바구니 테스트

팀의 API 명세가 확정되면 marketApi의 메서드를 실제 HTTP 요청으로 교체하세요. 실제 주문 가격/잔액/보상/리뷰 자격은 반드시 서버에서도 검증해야 합니다.

목업 데이터는 브라우저 localStorage의 `hackton-market-demo-v1` 키로 저장됩니다. UI 검증으로 추가한 테스트 주문·리뷰가 있을 수 있습니다. 새 브라우저에서는 초기 샘플로 시작합니다.

## 검증

`npm test`와 `npm run build` 통과. 브라우저에서 화면 이동, 수량 변경, 주문 후 영수증, 리뷰 등록, 퀘스트를 확인했습니다. 미사용 및 동일한 중복 에셋을 정리하여 public/assets에 54개 파일을 유지합니다. 화면별 참조는 src/assets/figma.json에서 공통 파일을 공유합니다. 전체 섹션의 완전한 일치 검증은 주문 완료 화면 확보 후 마무리해야 합니다.

### 가게별 데모 메뉴
시장칼국수, 달콤호떡, 골목카페에 각각 임시 메뉴 4종을 추가했습니다. 가게 정보 → 메뉴 → 수량 선택 → 주문/담기 → 영수증 → 리뷰 흐름을 공유합니다. 새 메뉴의 가격은 데모 코인이며 그림은 임시 이모지입니다. 가게 배경은 기존 UI 템플릿을 재사용합니다. 리뷰와 즐겨찾기는 가게별로 분리하고 기존 저장 기록은 서문분식으로 유지합니다. Figma 원본에는 변경이 없습니다.
