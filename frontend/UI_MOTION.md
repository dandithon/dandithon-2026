# 가벼운 UI 동작 효과

- 버튼: 누르는 동안 opacity 0.82, scale 0.97. 기본 지도 위 투명 버튼은 작은 어두운 오버레이로 피드백을 표시한다.
- 시장 진입: 180ms fade. 지도·캐릭터 상태는 유지한다.
- 창 열기: 190ms 이동·미세 확대·fade. 프로필은 상단 프로필 버튼 부근을 원점으로 사용한다.
- 창 닫기: 140ms 전환 후 150ms에 unmount. 닫는 동안 창과 배경 입력을 차단하고 중복 닫기 및 오래된 타이머를 정리한다.
- 새 창으로 전환하거나 작업 성공으로 화면이 바뀌는 경우 닫기 대기 없이 기존 창을 교체한다.
- `prefers-reduced-motion: reduce`에서는 창·화면 전환과 버튼 확대를 생략하고 즉시 닫는다.

위치·크기·blur를 매 프레임 바꾸지 않고 CSS transform·opacity를 사용한다. 새 라이브러리나 상시 애니메이션 루프는 추가하지 않았다. 단, 실제 휴대폰의 프레임 성능은 실기기 검수 대상이다.

검증: 에셋 79개·테스트 27개·빌드 통과. 로컬 live 브라우저에서 시작→시장, 프로필 열기·닫기, 전체 지도 열기·닫기와 배경 입력 차단 확인. 실제 iPhone·삼성 기기 및 OS 동작 줄이기 설정 검수는 미완료다.
