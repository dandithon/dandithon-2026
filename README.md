# 🏮 2026 단디톤 | 서문시장 2D 탐험 서비스

> 게임처럼 즐기는 전통시장, 서문시장에서 시작하는 새로운 경험

## 📌 프로젝트 소개

본 프로젝트는 2026 단디톤 해커톤 참가작으로,
대구 서문시장을 2D 게임형 공간으로 구현하여
젊은 세대가 전통시장을 친근하고 재미있게 경험할 수 있도록 하는 서비스입니다.

사용자는 캐릭터를 조작해 시장을 탐험하고,
다양한 가게의 메뉴를 확인하며 가상 코인으로 구매를 체험할 수 있습니다.

이를 통해 전통시장에 대한 심리적 진입 장벽을 낮추고,
게임 속 경험을 실제 시장에 대한 관심으로 연결하고자 합니다.

## 🎯 프로젝트 목표

- 젊은 세대의 전통시장에 대한 관심과 접근성 향상
- 게임 요소를 활용한 새로운 지역 문화 경험 제공
- 시장 상점과 먹거리를 자연스럽게 탐색할 수 있는 환경 조성
- 대구 서문시장을 시작으로 전국 전통시장으로 확장 가능한 서비스 구축

## 🎮 주요 기능

| 기능 | 설명 |
|------|------|
| 🗺️ 2D 시장 탐험 | 캐릭터를 움직이며 시장의 다양한 가게 탐색 |
| 🏪 가게 상호작용 | 상점 NPC와 대화하고 메뉴 및 가게 정보 확인 |
| 🪙 가상 코인 | 게임 내 코인을 활용한 메뉴 구매 체험 |
| 🍜 메뉴 탐색 | 가게별 대표 메뉴 및 한 줄 소개 확인 |
| ⭐ 리뷰 시스템 | 가게별 리뷰 조회 및 작성 |
| 📋 퀘스트 | 시장 탐험 미션 수행 및 코인 보상 |
| 👥 웨이팅 시각화 | 가게의 혼잡도를 캐릭터로 표현 (시연용 데이터) |

※ 세부 기능은 개발 과정에서 변경될 수 있습니다.
