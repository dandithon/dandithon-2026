# 시장에 가면 — Frontend

React + JavaScript + Vite 기반의 모바일 웹 프로젝트다. 현재는 FE A의 탐험 기반을 구현한 개발용 미리보기이며, 최종 디자인이나 서비스 완성본이 아니다.

## 실행

Node.js 22.12 이상을 사용한다. 저장소의 `frontend` 폴더에서 실행한다.

```sh
npm ci
npm run dev
```

브라우저에서 터미널에 표시된 로컬 주소를 연다. 초기 개발 서버는 `127.0.0.1`에만 열린다.

```sh
npm test
npm run build
npm run preview
```

Vite 설정은 [공식 가이드](https://vite.dev/guide/)를 참고한다. 현재 별도 환경변수나 API 키는 필요하지 않다. 폰트는 Google Fonts를 사용하며 로딩 실패 시 시스템 sans-serif로 표시된다. 최종 폰트는 디자이너와 확인 후 교체한다.

## 구현된 범위

- 시작 화면 → 탐험 화면 진입
- 개발용 맵·가게·캐릭터 표시, 조이스틱 드래그 및 방향키/WASD 이동
- 가게와 지도 경계 충돌, 캐릭터를 따라가는 지도 확대·축소
- 프로필·전체 지도·가게·퀘스트·영수증 패널 진입 및 닫기
- 모달이 열리면 이동 차단, 닫으면 위치 유지, Escape 닫기·포커스 복원
- 조이스틱 ON/OFF 전환, GPS 권한·수신·오류 상태 표시

## 미구현 및 임시 데이터

- 맵·캐릭터는 원본 Figma 에셋을 받기 전의 SVG 임시 에셋이다. 좌표·충돌 영역·가게·코인도 개발용이다.
- GPS 수신은 가능하지만, 실제 시장과 맵의 좌표 보정 기준이 없어 **GPS 캐릭터 이동은 구현하지 않았다**. GPS 모드에서는 가상 캐릭터를 숨기고 안내한다. 다시 조이스틱을 켜면 마지막 가상 위치에서 이어간다. 위치를 저장하거나 서버로 전송하지 않는다.
- 가상 이동으로 실제 방문 기록이나 퀘스트를 완료하지 않는다.
- 프로필은 탭과 연결 자리만 마련했다. 장비·착용·배지·내 리뷰는 미구현이다.
- 가게 상세·구매·영수증·퀘스트는 B 담당 화면을 연결할 자리이며 API 호출 또는 성공 처리를 하지 않는다.
- 혼잡도·예상 대기시간은 데이터 없음으로 표시한다. AI 예측이나 임의 대기줄은 구현하지 않았다.
- 데이터는 메모리에만 있으며 새로고침하면 초기화된다. API 계약은 아직 확정하지 않았다.

## 코드 구조 및 연결

```text
src/
  app/
    App.jsx              # 진입 및 탐험 화면
    GameContext.jsx      # 사용자·위치·이동 모드·패널 공유
    Panels.jsx           # 패널 프레임 및 B 화면 연결 자리
  features/exploration/
    MarketArt.jsx        # 교체할 임시 에셋 렌더러
    MarketScene.jsx      # 카메라·가게 선택·캐릭터 표시
    movement.js          # 렌더링과 분리된 좌표·충돌 계산
    useMovement.js       # 입력·프레임 처리, 숨김/포커스 이탈 시 정지
    useLocation.js       # GPS 상태, 감시 해제
    Joystick.jsx         # 포인터 입력
  mocks/market.js        # 실제 API와 구분한 개발 데이터
  styles.css             # 초기 탐험 스타일. 공통 UI는 B와 협의해 분리
```

### FE B에게 전달할 연결점

- `useGame().openPanel(type, shopId)`로 패널을 열고 `closePanel()`로 닫는다.
- `type`은 현재 `shop`, `receipts`, `quests`, `profile`, `map`을 사용한다. 이는 로컬 UI 계약이며 백엔드 계약이 아니다.
- 가게를 선택하면 `panel.shopId`가 전달된다. `Panels.jsx`의 `PendingPanel`을 실제 담당 화면으로 연결한다.
- 내 리뷰는 `ProfilePanel`의 해당 탭에 연결한다. 프로필 컨테이너 수정은 A와 조율한다.
- 코인 등 사용자 정보는 `GameContext`의 `user`를 공유한다. 구매 성공을 임의 확정하지 말고 API 계약 확정 후 서버 응답 갱신 방식을 함께 정한다.
- `GameContext`와 패널 프레임은 A 소유다. 공통 버튼·패널 스타일은 임시이며 B의 공통 UI 작업 시 대체한다.
- 지도 패널에서도 동일한 가게 식별자를 전달한다. 다른 패널로 전환되어도 가상 위치는 유지된다.

## 수동 확인 항목

- 조이스틱을 움직이다 손을 떼거나 포인터가 취소되면 정지하는지
- 방향키를 누른 상태에서 창을 벗어났다 돌아와도 계속 이동하지 않는지
- 가게·지도 경계를 통과하지 않는지, 확대해도 월드 위치가 바뀌지 않는지
- 패널이 열려 있는 동안 이동하지 않는지, 닫은 뒤 이전 위치가 유지되는지
- GPS 권한 거부·수신 실패 안내, ON/OFF 후 가상 위치 보존
- 작은 모바일 화면에서 버튼·모달·하단 조작부가 잘리지 않는지

자동 테스트는 이동 속도·경계·충돌·탭 복귀 시 큰 시간 차이를 검증한다. 실기기 GPS 및 터치 조작은 별도 확인이 필요하다.
